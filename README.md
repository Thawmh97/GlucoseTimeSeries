# GlucoseTimeSeries

Time Series Project to predict glucose at 30 minutes and 60 minutes.

## Overview

This repository contains tools for preprocessing and analyzing glucose time series data, with the goal of predicting glucose levels at 30 and 60 minutes in the future.

## Features

The `data_preprocessing.py` module provides comprehensive data exploration capabilities:

- **Initial Data Exploration**: Load and inspect glucose time series datasets
- **Summary Statistics**: Calculate comprehensive statistics for glucose readings
- **Patient Analysis**: Count unique patients and analyze patient-level information
- **Recording Analysis**: Count total recordings and recordings per patient
- **Time Duration Analysis**: Calculate the total monitoring time for each patient
- **Data Quality Assessment**: Identify missing values and data quality issues
- **Automated Reporting**: Generate detailed exploration reports

## Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Quick Start

### Using the Example Script

Run the example script to see the preprocessing module in action with sample data:

```bash
python example_usage.py
```

This will:
1. Create sample glucose time series data
2. Perform initial data exploration
3. Display summary statistics, unique patients, total recordings, and time duration per patient
4. Generate a detailed exploration report

### Using with Your Own Data

```python
from data_preprocessing import explore_glucose_data

# Quick exploration with one function call
explorer = explore_glucose_data(
    data_path='your_glucose_data.csv',
    patient_id_col='patient_id',
    timestamp_col='timestamp',
    glucose_col='glucose',
    save_report=True
)
```

### Advanced Usage

```python
from data_preprocessing import GlucoseDataExplorer

# Create explorer instance
explorer = GlucoseDataExplorer('your_glucose_data.csv')

# Load data
explorer.load_data(
    patient_id_col='patient_id',
    timestamp_col='timestamp',
    glucose_col='glucose'
)

# Get summary statistics
stats = explorer.get_summary_statistics()
print(stats)

# Get unique patients
unique_patients = explorer.get_unique_patients()

# Get total recordings
total_recordings = explorer.get_total_recordings()

# Get recordings per patient
recordings_per_patient = explorer.get_recordings_per_patient()

# Get time duration per patient
time_duration = explorer.get_time_duration_per_patient()
print(time_duration)

# Generate and display exploration report
explorer.print_exploration_report()

# Save report to file
explorer.save_exploration_report('exploration_report.txt')
```

## Data Format

The preprocessing module expects data in the following format:

| Column | Description | Type |
|--------|-------------|------|
| patient_id | Unique identifier for each patient | int/string |
| timestamp | Date and time of the glucose reading | datetime |
| glucose | Glucose value in mg/dL | float |

Additional columns (e.g., age, gender, etc.) are supported and will be included in the analysis.

**Supported file formats:**
- CSV (`.csv`)
- Excel (`.xlsx`, `.xls`)
- JSON (`.json`)

## Exploration Report

The module generates a comprehensive exploration report that includes:

1. **Dataset Overview**: Total records, columns, and basic information
2. **Patient Information**: Unique patients, average/median/min/max recordings per patient
3. **Recording Statistics**: Total number of glucose recordings
4. **Time Duration**: Average, median, min, and max monitoring duration per patient
5. **Glucose Statistics**: Mean, median, standard deviation, range, quartiles, and missing values
6. **Missing Values Summary**: Detailed breakdown of missing data
